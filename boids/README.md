# Boids — flocking simulation

A single, dependency-free HTML file. Open it by double-clicking `boids/index.html`, or from a terminal:

```
start "" "D:\code\coding-harness\boids\index.html"
```

Works offline via `file://` — no build step, no CDN, no external files. Move your mouse over the canvas to act as a predator; use the on-screen panel to tweak the rules and hit **RESET DEFAULTS** to restore them.
